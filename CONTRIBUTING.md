# Contributing

Ansible role that installs and configures Remi's SCL-packaged PHP on EL6/EL7 hosts.

## Development setup

See [AGENTS.md](AGENTS.md#commands) for the tooling this repo actually has — not repeated here.

## Opening a PR

Use this repo's PR template — link the ticket (Jira/Linear/an issue) and describe how the change was verified.

## Before you open a PR

- [ ] Change tested against a real playbook run, since this repo has no lint or CI configured
- [ ] Docs (`README.md`/`AGENTS.md`) updated if this changes how the role is built, run, or used
